SHOPVERSE — PHASE 7: WISHLIST, RECENTLY VIEWED आणि COUPONS

या आवृत्तीत नवीन सुविधा:
1. उत्पादन कार्डवरील ♡ बटणाने Wishlist मध्ये उत्पादन जतन करता येते.
2. wishlist.html मध्ये जतन केलेली उत्पादने काढता येतात किंवा Cart मध्ये टाकता येतात.
3. अलीकडे पाहिलेली उत्पादने Wishlist पानावर दिसतात.
4. Checkout मध्ये SAVE10, FREESHIP आणि WELCOME100 हे demo coupon codes आहेत.
5. ₹999 किंवा त्यापेक्षा जास्त subtotal असल्यास demo delivery मोफत; त्याखाली ₹49.
6. ऑर्डरमध्ये subtotal, shipping, discount आणि final total जतन होतात.

चालवणे:
1. ZIP extract करा.
2. त्या फोल्डरमध्ये Terminal उघडा.
3. python3 -m http.server 8000 चालवा.
4. http://localhost:8000 उघडा.

महत्त्वाच्या मर्यादा:
- Wishlist, cart, coupons आणि orders हे browser localStorage मधील demo data आहेत.
- Browser मध्ये असलेली coupon logic किंवा admin checks सुरक्षित व्यावसायिक नियम नाहीत.
- प्रत्यक्ष पैसे, सुरक्षित login, वेगवेगळ्या ग्राहकांमध्ये data sharing किंवा online stock sync यासाठी backend/database/payment provider लागेल.
- सर्व code HTML, CSS आणि Vanilla JavaScript मध्ये आहे.
