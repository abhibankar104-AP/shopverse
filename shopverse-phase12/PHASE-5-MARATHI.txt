SHOPVERSE — PHASE 5 (Admin Management)

या टप्प्यात:
- Admin dashboard वर active products, demo orders, demo sales आणि low-stock count.
- Products search/category filter.
- Product add/edit/delete.
- Order list आणि status update (Placed, Processing, Shipped, Delivered, Cancelled).
- Admin ने बदललेली product माहिती storefront, product details, cart आणि checkout मध्ये वापरण्यासाठी catalog overlay.

चालवणे:
1. ZIP Extract करा.
2. shopverse फोल्डरमध्ये Terminal उघडा.
3. python3 -m http.server 8000
4. http://localhost:8000 उघडा.
5. Admin: http://localhost:8000/admin/login.html

चाचणी:
- Customer login करा, उत्पादन add to cart करून demo order ठेवा.
- Admin login करून order status बदलून पाहा.
- Add product, Edit आणि Delete तपासा.
- Storefront वर परत जाऊन नवीन/बदललेले उत्पादन दिसते का तपासा.

मर्यादा:
- Product overrides/deletions आणि orders या browser च्या localStorage मध्येच साठतात. alldata.json फाइल आपोआप बदलत नाही.
- दुसऱ्या ब्राउझर/device वर डेटा दिसणार नाही.
- Admin credentials JavaScript मध्ये आहेत आणि browser-side access checks सुरक्षित नाहीत.
- हा learning demo आहे. खऱ्या दुकानासाठी backend API, database, server-side authentication/authorization, input validation आणि payment provider आवश्यक आहेत.
