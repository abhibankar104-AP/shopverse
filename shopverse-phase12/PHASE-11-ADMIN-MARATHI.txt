SHOPVERSE — PHASE 11: ADMIN PANEL / PRODUCT MANAGEMENT

या आवृत्तीत काय जोडले/सुधारले:
- Admin dashboard मध्ये उत्पादनांचे फोटो छोटे preview म्हणून दिसतात.
- नवीन उत्पादन जोडता येते.
- उत्पादनाचे नाव, प्रकार, SKU, फोटोचा पत्ता, मूळ किंमत, ऑफर किंमत, साठा, rating, वर्णन आणि featured स्थिती बदलता येते.
- प्रत्येक उत्पादनासाठी Quick edit price सुविधा जोडली आहे.
- उत्पादन हटवता येते; ते सध्याच्या ब्राउझरच्या catalogue मधून लपवले जाते.
- नाव/SKU/ID शोध आणि प्रकारानुसार filter उपलब्ध.
- सध्याच्या catalogue चा JSON backup डाउनलोड करता येतो.
- browser मधील सर्व catalogue बदल मूळ demo data वर परत आणता येतात.
- Orders विभागात demo order status बदलण्याची सुविधा कायम.

कसे चालवायचे:
1. ZIP काढा.
2. प्रकल्पाच्या मुख्य फोल्डरमध्ये टर्मिनल उघडा.
3. python3 -m http.server 8000 चालवा.
4. http://localhost:8000/admin/login.html उघडा.
5. वरील demo login वापरा.

महत्त्वाची मर्यादा:
हे HTML/CSS/JavaScript चे browser-only demo आहे. बदल localStorage मध्ये जतन होतात; ते data/alldata.json फाइल बदलत नाहीत आणि दुसऱ्या browser/device वर आपोआप दिसत नाहीत. Admin login browser-side आहे, त्यामुळे खऱ्या दुकानासाठी सुरक्षित नाही. Production साठी backend API, server-side admin authentication/authorization आणि shared database आवश्यक आहे. JSON export हा backup/reference आहे; तो मूळ फाइल आपोआप बदलत नाही.
